# 提示词工程（image-forge）

> 模型怎么选、参数怎么配 → 看 `decision-tree.md`（实测决策树）；本文件只管 **prompt 文本怎么写**。
> 状态：`[docs]` 官方文档与社区验证经验；与 decision-tree 的实测规则配合使用。

## 一、文生图 prompt 五层结构

```
[主体] + [动作/姿态] + [环境] + [光线] + [镜头/风格]
```

1. **主体**：具体名词+关键特征。"一只戴围巾的橘猫" ✓；"一只可爱的猫" ✗（"可爱"交给风格层）
2. **动作/姿态**：动词要可见。"蹲坐窗台回望镜头"、"手捧咖啡看向窗外"
3. **环境**：地点+氛围元素。"深夜便利店门口，雨水积水反射招牌"
4. **光线**：最容易被忽略、提升最大的一层。黄金时刻逆光 / 阴天柔光 / 霓虹色温 / 体积光 / 烛光
5. **镜头/风格**：35mm 纪实 / 微距特写 / 广角环境 / 胶片颗粒 / 水彩 / 赛博朋克动画

示例（五层齐全）：
> 一位穿米色风衣的年轻女性（主体）撑伞走过巷口，回头看向镜头（动作），江南老街雨后，青石板积水（环境），黄昏侧逆光，伞沿挂水珠（光线），35mm 纪实感，浅景深（镜头/风格）

**反模式**：堆砌质量词（"超高清、8k、大师级、杰作"）在新一代模型上收益趋零，五层信息密度才是关键。负面描述写进正向 prompt 会反噬（"没有路人"→出现路人），要用参数层解决（模型有 negative 才用）。

## 二、编辑（图生图）prompt = 指令句

编辑模式写**指令**，不写描述：

| 意图 | 指令句式 |
|---|---|
| 精修 | "精修这张照片：去除杂物，提升皮肤质感，保持构图与人物身份不变" |
| 换背景 | "把背景换成黄昏海滩，人物与光照关系保持不变" |
| 去物/去人 | "移除画面右侧的路人，用地面纹理自然填补" |
| 改姿势/换装（插画） | "让她举起右手比心，换成冬季校服，其余保持一致" |
| 风格化重绘（允许重绘） | "以这张图为参考，重新构想为吉卜力风格场景" |

**保身份三句话**（写实精修必带）："保持人物面部身份不变 / 保持构图视角不变 / 只修改 X，其余不动"。通道选择对编辑保真影响巨大（nb21@fal SSIM 0.975 vs grok2@fal 0.746）——**选型听 decision-tree 的，别靠 prompt 补**。

## 三、分模型 prompt 偏好

### grok2（T2I 主力，写实强）
- 五层结构直给，写实摄影语汇响应好（镜头/光圈/胶片）
- 迭代用 `--quality low`，出稿 `medium`；极端画幅（19.5:9 等）是独门

### nb21（编辑之王 + 插画）
- 编辑：指令句 + 保身份三句话（`--image` 自动路由 /edit）
- 文生：插画风/概念图表现好；极端画幅 21:9/4:1/1:4 独有；`--seed` 复现（仅 fal）

### gpt2（文字渲染 + 透明底）
- 画面内文字：**引号内写原文**——"便利店招牌上写着'24小时营业'，灯箱发光"
- 文字要少而大（一句以内最稳）；透明底 `--background transparent --format png`

### flare / sunburst（2.5 精修档）
- 默认 quality=max，prompt 同 grok2 五层即可
- 重编辑意图明确写"保持构图，只改 X"；flare 写实通透、sunburst 为 2.5 质量档备选

## 四、为下游服务的 prompt（家族联动）

- **video 首帧**：`--aspect 9:16`（竖屏）或 16:9 出图 → `video-forge gen-video --image`，构图在图里定，视频 prompt 只写运动
- **一致性角色**：先用 nb21 编辑模式定妆（同 seed），再以定妆图为首帧/参考
