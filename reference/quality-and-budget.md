# 质量验收与预算纪律（按需读取）

## 视觉验收清单（每张生成后执行）

1. 用 Read 内嵌展示图片（只给路径=没交付）
2. 对照生成意图逐项核销：要删的删了吗？要改的改了吗？
3. 编辑任务：SSIM 对比输入输出（>0.9 原地）；大面积场景替换按区域人工复核
4. 身份敏感任务（人像/角色）：五官/表情/服饰/配饰逐项比对
5. 失败或漂移→按 `reference/lessons.md` 对照根因，改提示词重试（先拧免费旋钮）

## 预算纪律（budget.mjs）

- 会话首次生图前跑 `budget.mjs --check`，余额告知用户
- 月用量 ≥80%：每次生成前提醒余额
- 月用量 ≥100%：**停止生成**，继续须用户明示同意
- 用户问花费：跑 `budget.mjs` 用真实账本回答，不估算
- 账本是估算；平台的 Available credits 才是硬上限，用户报出真实余额时以 min(预算剩余, 真实余额) 为准

## 成本决策树

```
编辑现成照片？
├─ 写实人像精修 → nb21（SSIM 0.97 最高，$0.08）
├─ 大量试错/求快 → grok2（13s，$0.06）
└─ 质感决赛/客户不差钱 → flare（high ≈$0.16）
文生图？
├─ 一般插画/素材 → grok2
├─ 画面含大量文字 → gpt2（≈$0.16）
├─ 透明底素材 → 白底生成 + cutout.mjs（全模型通用路线）
└─ 特殊画幅 → 19.5:9 只有 grok2；21:9/4:1 只有 nb21
降本旋钮：候选期默认档；openai 系 medium 省 ~70%；xai low 省 1/3；终稿才升 max
```
