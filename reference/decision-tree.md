# 需求 → 参数决策树（智能执行规则表）

> 用途：agent 收到自然语言生图需求时，按本表推导最佳参数与提示词策略。
> 所有规则来自实测（2026-10-06~09，fal+Replicate 双通道 20+ 次）与商业修图行业标准，可解释、可修订。
> 执行时在返回消息中列出「所选参数+依据」，用户可干预。

## 一、需求解析（从自然语言提取六个维度）

| 维度 | 从需求中找什么 | 示例 |
| --- | --- | --- |
| 任务类型 | 编辑现有图（给图/改图/精修/去人/换背景）还是文生图（画/生成/设计） | "这张照片帮我修一下"=edit |
| 主体内容 | 画什么主体、什么动作/姿势、什么场景 | "橘猫坐窗台" |
| 风格倾向 | 写实/插画/水彩/像素/胶片/日系/赛博…（不确定则问或默认自然写实） | "水彩风" |
| 画幅暗示 | 头像/壁纸/banner/海报/封面 → 方/竖/横；手机屏=9:16，公众号头图=2.35:1 | "做头像"=1:1 |
| 文字元素 | 画面里要不要出现文字（招牌/标题/标语） | "带标题的封面"=有字 |
| 质量档位 | 候选草稿 / 日常交付 / 高价值终稿 / 印刷放大 | "先出几版看看"=候选 |

## 二、模型决策（按优先级顺序匹配，命中即停）

| 条件（命中任一） | 模型 | 通道 | 依据 |
| --- | --- | --- | --- |
| 编辑现有**真人/写实照片**（精修/去物/去人/换景） | `nb21` | fal（实测 0.975）| 备选 sunburst@fal 0.969；grok2 精修用 Replicate 通道（0.951）而**非** fal（0.746）——同模型跨通道编辑行为差异巨大，选型以 edit_ssim_verified 为准 |
| 编辑**插画/卡通角色**（改姿势表情换装） | `grok2` | replicate（0.951，最快） | 插画对"原地"要求低；或 nb21@fal |
| 文生图 + 画面**含大量文字**（招牌/海报/带字封面） | `gpt2` | fal | OpenAI 系文字渲染硬优势 |
| 文生图 + 需要**透明底** | `flare` 或 `gpt2` | fal | 仅 2.5/部分 openai 端点支持 background=transparent；备用路线=白底+cutout |
| 文生图 + **草稿候选/大量试错** | `grok2` | fal | 13-16s 最快、$0.04-0.06 最省 |
| 文生图 + **特殊画幅** 19.5:9/9:19.5 | `grok2` | 均可 | 仅 xai 与 google 有极端画幅档 |
| 文生图 + **超宽/巨幅** 21:9/4:1/8:1 | `nb21` | replicate 或 fal | 极端比例 google 系最全 |
| 文生图 + **高质感终稿**（写实氛围图） | `flare`（quality=high） | fal | 2.5 系质感通透；max 档更贵按需 |
| 以上皆不命中（一般插画/素材） | `grok2` | fal | 默认主力：快+省+质量够 |

**通道补充规则**：
- 默认 fal（编辑保真已实测）。用户点名 Replicate、或 fal 余额不足、或需要跨平台比价时切 Replicate。
- Replicate 通道做**编辑**仅限"重新构想"类（允许场景重绘）；写实精修类编辑在 Replicate 通道直接拒绝并说明原因（教训 C1）。
- nb21 需要可复现时（`--seed`），仅 fal 通道支持。

## 三、画幅推导（从用途到枚举）

| 用途关键词 | 画幅 | 落到通道枚举 |
| --- | --- | --- |
| 头像/图标/方形帖 | 1:1 | 全通道 |
| 手机壁纸/短视频封面/故事 | 9:16（手机全屏可 9:19.5→grok2） | 全通道 |
| 公众号封面/banner | 16:9（超宽 21:9→nb21） | 全通道 |
| 写真照片/人像卡 | 3:4（人像摄影惯例） | 全通道 |
| 电商主图 | 1:1 或 3:4（平台规范优先） | 全通道 |
| 印刷海报 | 3:4 或 2:3 + 高分辨率档 | 全通道 |
| 桌面壁纸 | 16:9 | 全通道 |
| 用户给了参考图 | 编辑模式：不传画幅（跟随输入）——fal 自动；Replicate nb21 显式 match_input_image | — |

## 四、分辨率 / 质量档（按交付档位）

| 档位 | 判断 | 参数 |
| --- | --- | --- |
| 候选/草稿 | "先看看""出几版""试试" | 全默认；openai 系 quality=medium 省 70% |
| 日常交付 | 无特殊说明的正式出图 | nb21=grok2 默认；openai 系 quality=high；分辨率默认 1K |
| 高价值终稿 | "客户用""终稿""封面""印刷" | 分辨率升 2K（xai/google）或 square_hd（openai）；openai quality=high（max 仅用户点名"极致"时） |
| 印刷/大画幅 | "海报打印""大幅" | 4K（nb21）或 2K（grok2）+ 与用户确认尺寸 |

## 五、格式选择

| 场景 | 格式 |
| --- | --- |
| 网页/小程序展示 | webp（体积最小；后续还要处理则 png） |
| 要抠图/二次编辑 | png（无损中间产物） |
| 要打印 | png 或 jpeg（quality 拉满） |
| 平台强制 jpg | jpeg |
| 透明底 | png（background=transparent 仅 openai 2.5 端点；否则白底+cutout.mjs） |

## 六、提示词组装规则（与参数同等重要）

1. **六要素顺序**：主体（外观/动作/细节全显式）→ 构图 → 场景 → 风格 → 光线 → 编辑指令
2. **硬动词**：删除用"删除/全部移除"，禁"简化/清理"；每条删除配补全方案
3. **正向表述**：永不写"禁止/不要 X"（会诱导 X），写"输出单张完整照片"
4. **面部瑕疵枚举**（人像精修时）：法令纹/痘痘/痘印/黑眼圈/泛红/碎发/油光——按工单实际存在的逐项点名，禁"小瑕疵"笼统词
5. **身份锁死**（人像）：五官/表情/姿势/发型/服装纹样/配饰逐条复述；只描述外观不写族名
6. **肤色连接**：人像必写"面部、颈部、手臂与手部肤色一致过渡"
7. **编辑最小体**：编辑任务参数只发 prompt+输入图（+openai 质量档）；画幅跟随输入图，显式要求才传

## 七、执行后验收（每张必做）

1. Read 内嵌展示（路径≠交付）
2. 对照需求逐项核销
3. 编辑任务 SSIM：>0.9 原地 ✓ / 0.7-0.8 中度重绘（报告用户）/ <0.5 整幅重绘（判失败，查 lessons.md）
4. 身份敏感：8 项锚点逐项比对
5. 失败→查 reference/lessons.md 对应根因→改提示词重试（重试前告知用户 +$成本）
